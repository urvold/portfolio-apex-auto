# APEX AUTO: русификация и локальные сенсорные жесты

Изменения подготовлены локально. Отправка в GitHub и обновление Pages требуют подтверждения пользователя.

## Интерфейс

Переведены RESTORE / REFINE / PROTECT, THE HUMAN BEHIND THE DETAIL, DETAIL EXPLORER, AUTO / ESTHETICS, APEX CARE, FORM / FINISH / FEELING, PRECISION / IN EVERY LINE, VISUAL ARCHIVE, Silver, Black leather, Graphite и подсказка клавиатуры. Бренд APEX AUTO сохранён. Проверены также alt, aria-label, placeholder, title и CSS-псевдоэлементы. Технические идентификаторы и пути не переводились.

Красная полоса на смартфонах использует три строки вместо тесной горизонтальной компоновки. Уточнены размеры и переносы русских подписей в шапке, интерактивном обзоре и полноэкранной галерее. Нового редизайна нет.

## До / После

Причина перехвата жеста: прежнее touch-action: pan-y pinch-zoom разрешало браузеру вертикальную прокрутку внутри сравнения. Теперь touch-action: none установлен только на сравнении. Вне компонента прокрутка остаётся обычной; глобальной блокировки body нет.

Сохранены Pointer Events, единое числовое состояние, расчёт clientX через getBoundingClientRect, границы 0–100%, ARIA и клавиатурное управление. Захват и освобождение указателя проверяют доступность API. pointerup, pointercancel и lostpointercapture сбрасывают перетаскивание. Запрещены выделение и стандартное перетаскивание изображений. Переходы для маски и разделителя отключены, изображения неподвижны.

## Воспроизведение

```sh
APEX_BASE_PATH=/portfolio-apex-auto/ APEX_SITE_URL=https://urvold.github.io/portfolio-apex-auto npm run build
APEX_BASE_PATH=/portfolio-apex-auto/ APEX_SITE_URL=https://urvold.github.io/portfolio-apex-auto npm run check:pages
APEX_BASE_PATH=/portfolio-apex-auto/ npm run preview -- --port 4180 --strictPort
```

Локальный адрес: http://localhost:4180/portfolio-apex-auto/ . В другом терминале: `python tests/localization_touch.py`.

Артефакты текущей проверки находятся в игнорируемой Git папке artifacts/ru-touch/. Старые Lighthouse-отчёты относятся к прошлому этапу и не являются результатами этого исправления.

## Ограничения

Физический iPhone не использовался. Linux WebKit не равнозначен Safari iOS. Публичный API Playwright WebKit не предоставляет непрерывный сенсорный поток: для него проверяются нативное касание с захватом, программные pointermove во время активного касания и нативное диагональное перетаскивание мышью. Нативный диагональный сенсорный поток проверен в Chromium. До публикации полезно повторить сценарий на настоящем iPhone.
